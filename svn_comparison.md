1. в Git ветка это просто указатель на коммит, а в SVN ветка — это копия структуры каталогов в репозитории (серверная операция, создающая новую директорию с историей)
2. SVN централизованная система: коммит сразу отправляется на сервер, локально зафиксировать изменения нельзя.
3. Нативная блокировка файлов, эффективная работа с тяжелыми бинарными файлами (GameDev, CAD, дизайн), контроль прав доступа на уровне отдельных папок, частичная загрузка только нужных директорий без скачивания всей истории, простота освоения для нетехнических специалистов
